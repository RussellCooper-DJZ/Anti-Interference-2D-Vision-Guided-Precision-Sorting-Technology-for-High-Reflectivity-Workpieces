## 二、WHY 目标：核心价值与模块职责

### 2.1 核心价值命题

> **在复杂工业环境下，对高反光金属工件实现 <0.5mm 精度的边缘识别与机器人精准抓取。**

这一定义决定了所有迭代的价值判断标准：
- ✅ **直接贡献**：改进边缘识别精度、抑制高光干扰、加速推理、提升抓取成功率
- ⚠️ **间接贡献**：数据增强、训练优化、模型压缩、嵌入式部署
- ❌ **偏离贡献**：通用 MLOps 平台、多租户 SaaS、混沌工程、成本优化

### 2.2 核心模块职责边界

| 模块 | 输入 | 输出 | 职责边界 | 核心价值指标 |
|------|------|------|---------|-------------|
| `vision/` | BGR 图像 (H,W,3) | 分割掩膜 + 边缘图 + 测量值 | **感知层**：从像素到语义 | IoU > 0.85, 边缘 F1 > 0.80, 定位误差 < 0.5mm |
| `data/` | 场景参数 / 真实图像 | 增强图像 + 合成图像 + 加载器 | **数据层**：解决数据稀缺 | 物理合理性、mask-图像一致性 |
| `training/` | 数据集 + 配置 | 模型权重 (.pth) | **训练层**：产出可部署模型 | 收敛稳定性、最佳检查点 |
| `robot/` | 像素坐标 + 标定参数 | ABB 运动指令 (JSON/UDP) | **执行层**：视觉-机器人闭环 | 通信延迟 < 10ms, 指令成功率 > 99.9% |
| `embedded/` | 原始图像帧 | 预处理后的特征 / 推理结果 | **加速层**：边缘实时推理 | 推理延迟 < 50ms, 内存 < 1MB |
| `main_pipeline.py` | 摄像头/文件 | 机器人指令 + 可视化结果 | **集成层**：端到端交付 | 端到端时延 < 500ms |

### 2.3 迭代价值判断标准

任何迭代必须通过以下问题之一才有价值：

1. **是否直接改进了边缘识别精度？**（新注意力、新卷积、新损失）
2. **是否增强了对高反光的鲁棒性？**（HDR、光度立体、修复）
3. **是否提升了定位/测量精度？**（亚像素、RANSAC、标定）
4. **是否加速了推理或降低了部署成本？**（量化、剪枝、SIMD、多后端）
5. **是否解决了数据稀缺问题？**（合成生成、域适应、增强）
6. **是否提升了机器人抓取成功率？**（路径规划、碰撞检测、手眼标定）

**不满足以上任何一条的迭代 = 偏离主线。**
