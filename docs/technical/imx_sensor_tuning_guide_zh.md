# Sony IMX 系列传感器高反光抑制寄存器调优指南

## 1. 引言

在工业机器视觉中，面对高反光金属工件（如不锈钢、电镀件、铝合金），单纯依靠后端的图像处理算法往往难以完全恢复饱和的像素。本指南旨在指导开发者如何通过直接配置 Sony IMX 系列传感器（如 IMX290、IMX335、IMX415 等）的底层寄存器，从**光学采集源头**抑制镜面反射光斑。

## 2. 核心寄存器与配置策略

### 2.1 启用 DOL-HDR (Digital Overlap HDR) 模式
Sony 的 DOL-HDR 技术允许传感器在单个帧周期内连续采集多重曝光（长、中、短曝光），并通过 CSI-2 接口输出交织的数据流。
*   **配置方法**：通过向寄存器 `0x300C` 写入 `0x01`（以 IMX335 为例），启用 2-frame DOL-HDR 模式。
*   **作用**：短曝光专门用于捕获高光区域的边缘细节，长曝光用于捕捉阴影区域，从源头避免单一曝光导致的“全黑或全白”。

### 2.2 模拟增益（Analog Gain）最小化策略
在高反光环境下，盲目提高增益会导致满阱容量（Full Well Capacity）迅速饱和。
*   **配置方法**：强制将模拟增益寄存器（如 `0x30E8`）设定为 `0x00`（即 0dB）。
*   **作用**：最大化传感器的动态范围，延迟高光饱和点的到来。

### 2.3 黑电平偏移（Black Level Offset）动态调节
*   **配置方法**：微调寄存器 `0x3015`。
*   **作用**：在强车间顶灯或杂散光干扰下，适当提高黑电平可以过滤掉低强度的环境噪声，使工件轮廓与背景分离得更清晰。

## 3. 材质自适应调优建议

| 工件材质 | 推荐增益设置 | HDR 模式 | 特殊寄存器调整 |
| :--- | :--- | :--- | :--- |
| **不锈钢 (Stainless Steel)** | 0 dB | 开启 (DOL-HDR) | 标准黑电平 (10-15) |
| **铝合金 (Aluminum)** | 2-3 dB | 开启 | 略微提升曝光时间 |
| **电镀件 (Electroplated)** | 0 dB | 强制开启 | 超短曝光序列 (100us) |

## 4. 结论

通过底层寄存器调优与 RA8P1 内置 Simple ISP 的联动，开发者可以构建一个“硬件源头抗光斑 + 软件深度学习推理”的闭环系统，彻底解决高反光工件“看不清”的痛点。
