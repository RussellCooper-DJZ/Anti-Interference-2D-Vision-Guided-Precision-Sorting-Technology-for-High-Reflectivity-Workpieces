# 高反光金属工件训练数据收集与标注指南
# Training Data Collection and Annotation Guide for High-Reflectivity Metal Workpieces

本指南旨在指导如何针对汽车门板钢、铝合金型材等高反光工业工件，构建高质量的深度学习训练数据集。

---

## 一、 图像采集策略 (Image Collection Strategy)

高反光工件的成像质量直接决定了模型对真实边缘的提取能力。

### 1. 光学环境搭建
*   **光源选型**：
    *   **穹顶光源 (Dome Light)**：提供高度均匀的漫射光，是消除金属表面局部镜面反射的最佳选择。
    *   **同轴光源 (Coaxial Light)**：适用于检测平整金属表面的微小凹坑或划痕，但可能加剧整体反光。
    *   **低角度环形光**：用于突出边缘轮廓，但需注意避免产生“虚假边缘”。
*   **偏振片 (Polarizer)**：在相机镜头前安装偏振片，并配合偏振光源，可有效滤除特定角度的镜面反射。

### 2. 多重曝光采集 (Multi-Exposure)
为了训练 HDR 融合模型或增强分割模型的鲁棒性，每个场景建议拍摄 3-5 张不同曝光时间的图像：
*   **低曝光 (Underexposed)**：清晰捕捉高光区域内的细节（如反光斑中心的工件纹理）。
*   **标准曝光 (Standard)**：捕捉大部分中间调区域。
*   **高曝光 (Overexposed)**：捕捉暗部区域及工件阴影边缘。

### 3. 场景多样性
*   **背景变化**：使用不同材质（黑色橡胶、灰色传送带、金属工作台）作为背景。
*   **干扰项**：在工件周围放置油污、切屑、工具或其他金属零件。
*   **光照扰动**：引入环境光干扰（如厂房窗户日光、移动的人影）。

## 二、 标注规范 (Annotation Specification)

对于高反光工件，标注的**一致性**比数量更重要。

### 1. 标注工具推荐
*   **LabelMe**：开源、轻量，支持多边形标注，适合生成 JSON 格式。
*   **CVAT**：支持团队协作，具有自动插值和 AI 辅助标注功能。

### 2. 核心标注对象
*   **Mask (分割掩膜)**：
    *   **类别名**：`workpiece`
    *   **标注方式**：沿工件**真实物理边缘**进行多边形闭合标注。
    *   **注意**：即使边缘被强反光遮挡，也要根据几何先验（如直线、圆弧）进行“脑补”连接，确保掩膜完整。
*   **Edge (边缘掩膜 - 可选)**：
    *   本代码库中的 `train.py` 会根据 Mask 自动生成边缘图，无需手动标注。

### 3. 特殊情况处理
*   **反光斑 (Glare/Specular)**：不要将反光斑标注为背景或孔洞，它们属于工件表面。
*   **阴影 (Shadow)**：严禁将阴影标注为工件。标注边缘应位于工件实体与阴影的交界处。
*   **遮挡 (Occlusion)**：如果工件被其他物体遮挡，仅标注可见部分。

## 三、 数据集组织结构 (Dataset Structure)

建议按照以下结构组织您的数据集，以便直接适配 `train.py`：

```text
datasets/metal_sorting_db/
├── train/
│   ├── images/         # 原始图像 (png/jpg)
│   │   ├── scene_001_exp1.png
│   │   ├── scene_001_exp2.png
│   │   └── ...
│   └── masks/          # 对应掩膜 (单通道 PNG, 0=背景, 255=工件)
│       ├── scene_001_exp1.png
│       ├── scene_001_exp2.png
│       └── ...
├── val/                # 验证集 (结构同上)
└── test/               # 测试集 (结构同上)
```

## 四、 针对汽车门板钢与铝合金的专项建议

### 1. 汽车门板钢 (Automotive Door Panels)
*   **挑战**：面积大、曲率变化多、涂油表面反光极强。
*   **采集**：重点采集拉延筋、冲压孔位周边的图像，这些地方是抓取点定位的关键。
*   **标注**：由于冲压件边缘可能存在毛刺或翻边，标注时应统一以“设计轮廓线”为准。

### 2. 铝合金型材 (Aluminum Profiles)
*   **挑战**：表面具有明显的拉丝纹理，光线会沿纹理方向形成线状高光。
*   **采集**：改变型材放置角度（水平、垂直、倾斜），观察高光随纹理方向的变化。
*   **增强**：在 `data_augmentation.py` 中增加 `LinearGlare`（线性高光）的比例。

## 五、 质量检查清单 (Quality Checklist)

在开始训练前，请检查：
1. [ ] 所有图像是否已调整为统一比例或符合模型输入尺寸（如 512x512）。
2. [ ] 掩膜图像是否为单通道（8-bit Gray），且像素值仅包含 0 和 255。
3. [ ] 掩膜与原图的文件名是否完全一致。
4. [ ] 是否包含至少 10% 的“负样本”（即不含工件、仅有背景和干扰项的图像）。

---
**提示**：您可以先使用本项目提供的 `SyntheticMetalWorkpieceGenerator` 生成 1000 张合成数据进行预训练，再加入 100-200 张精细标注的真实数据进行微调 (Fine-tuning)，这样可以获得最佳的工业落地效果。
