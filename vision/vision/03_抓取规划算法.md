## 项目背景

**Anti-Interference-2D项目**中，抓取规划是将视觉感知结果转化为机器人动作的关键环节。项目针对高反光钢板工件，设计了从抓取点选择、路径规划到执行控制的完整抓取系统。

本章节系统阐述抓取规划算法原理、路径优化方法及工程实现方案。

## 1. 抓取规划概述

### 1.1 问题定义[51†][52†]

抓取规划（Grasp Planning）是机器人从初始状态出发，找到一条无碰撞的路径，将末端执行器移动到目标物体的抓取位置，并完成抓取动作的整个过程。在钢板搬运场景中，抓取规划需要解决：

| 问题 | 描述 | 挑战 |
|-----|------|------|
| **抓取点选择** | 确定最佳的抓取位置和姿态 | 钢板表面高反光、边缘特征不明显 |
| **抓取姿态规划** | 确定夹爪的开口角度和倾斜角度 | 堆叠钢板、多层钢板区分 |
| **路径规划** | 从当前位置移动到抓取点的无碰撞路径 | 车间障碍物、其他钢板 |
| **抓取执行** | 闭环控制，抓取过程中的调整 | 钢板滑动、定位误差 |

### 1.2 抓取规划系统框架[52†]

```
┌──────────────────────────────────────────────────────────┐
│                    视觉感知层                             │
│  钢板检测 → 边缘提取 → 缺陷识别 → 位姿估计 → 抓取点选择   │
└──────────────────────────────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────┐
│                    规划决策层                             │
│  空间建模 → 碰撞检测 → 路径规划 → 抓取策略 → 姿态优化     │
└──────────────────────────────────────────────────────────┘
                            ↓
┌──────────────────────────────────────────────────────────┐
│                    运动控制层                             │
│  轨迹生成 → 速度规划 → 电机控制 → 力控抓取 → 质量检测     │
└──────────────────────────────────────────────────────────┘
```

### 1.3 抓取规划的数学描述[51†]

**抓取配置**可以用以下参数描述：

| 参数 | 符号 | 说明 |
|-----|------|------|
| 位置 | $(x, y, z)$ | 夹爪中心的三维坐标 |
| 姿态 | $(\alpha, \beta, \gamma)$ | 绕X/Y/Z轴的旋转角 |
| 开口宽度 | $w$ | 夹爪两指之间的距离 |
| 抓取力 | $F$ | 夹爪施加的压力 |

**抓取质量评估函数**：
$$Q(g, O) = w_1 \cdot S_{reachability} + w_2 \cdot S_{stability} + w_3 \cdot S_{safety} + w_4 \cdot S_{efficiency}$$

其中：
- $S_{reachability}$：可达性评分
- $S_{stability}$：稳定性评分（考虑重力和摩擦力）
- $S_{safety}$：安全性评分（避开缺陷区域）
- $S_{efficiency}$：效率评分（路径长度、时间）

## 2. 抓取点选择算法

### 2.1 基于边缘特征的抓取点选择[51†]

根据钢板边缘特征确定最佳抓取位置：

| 特征 | 抓取策略 | 适用场景 |
|-----|---------|---------|
| **边缘完整性** | 沿边缘抓取，避免缺陷区域 | 单层钢板、有明显边界 |
| **边缘曲率** | 在曲率较小处抓取，稳定性好 | 曲面钢板、异形件 |
| **边缘距离** | 距边缘一定距离，避免应力集中 | 薄板、切割后钢板 |
| **缺陷分布** | 绕开缺陷区域，选择正常区域 | 有锈蚀、划痕的钢板 |

**Anti-Interference-2D项目抓取点选择策略**：
```python
class GraspPointSelector:
    """Anti-Interference-2D项目抓取点选择器"""

    def __init__(self, config):
        self.min_edge_distance = config.get('min_edge_distance', 30)  # mm
        self.max_edge_distance = config.get('max_edge_distance', 100)  # mm
        self.defect_safe_margin = config.get('defect_safe_margin', 50)  # mm

    def select_grasp_points(self, steel_contour, defect_regions, edge_quality_map):
        """
        选择抓取点

        Args:
            steel_contour: 钢板轮廓点
            defect_regions: 缺陷区域列表 [{'bbox': [x1,y1,x2,y2], 'type': '划痕'}, ...]
            edge_quality_map: 边缘质量图（越高越好）

        Returns:
            grasp_points: 候选抓取点列表 [{'point': (x,y), 'angle': θ, 'quality': score}, ...]
        """
        candidates = []

        # 沿轮廓采样候选点
        for i, point in enumerate(steel_contour):
            x, y = point

            # 检查距边缘距离
            edge_dist = self._compute_edge_distance(x, y, steel_contour)
            if not (self.min_edge_distance <= edge_dist <= self.max_edge_distance):
                continue

            # 检查是否在缺陷安全区域外
            if self._is_near_defect(x, y, defect_regions):
                continue

            # 计算抓取角度（法线方向）
            angle = self._compute_grasp_angle(i, steel_contour)

            # 评估抓取质量
            quality = self._evaluate_grasp_quality(
                x, y, angle, edge_quality_map, defect_regions, steel_contour)

            candidates.append({
                'point': (x, y),
                'angle': angle,
                'quality': quality,
                'edge_distance': edge_dist
            })

        # 按质量排序
        candidates.sort(key=lambda c: c['quality'], reverse=True)

        return candidates[:10]  # 返回top10

    def _compute_edge_distance(self, x, y, contour):
        """计算点到边缘的最短距离"""
        min_dist = float('inf')
        for px, py in contour:
            dist = np.sqrt((x - px)**2 + (y - py)**2)
            min_dist = min(min_dist, dist)
        return min_dist

    def _is_near_defect(self, x, y, defect_regions):
        """检查是否靠近缺陷区域"""
        for defect in defect_regions:
            x1, y1, x2, y2 = defect['bbox']
            # 扩展安全边界
            margin = self.defect_safe_margin
            if (x1-margin <= x <= x2+margin) and (y1-margin <= y <= y2+margin):
                return True
        return False

    def _compute_grasp_angle(self, idx, contour):
        """计算抓取角度（轮廓法线方向）"""
        n = len(contour)
        prev_idx = (idx - 1) % n
        next_idx = (idx + 1) % n

        dx = contour[next_idx][0] - contour[prev_idx][0]
        dy = contour[next_idx][1] - contour[prev_idx][1]

        # 法线方向（垂直于切线）
        angle = np.arctan2(dx, -dy)  # 负Y因为图像坐标系

        return angle

    def _evaluate_grasp_quality(self, x, y, angle, edge_quality_map, defect_regions, contour):
        """评估抓取质量"""
        quality = 1.0

        # 边缘质量权重
        quality *= edge_quality_map.get((int(x), int(y)), 0.5)

        # 距边缘距离权重（中间位置最好）
        edge_dist = self._compute_edge_distance(x, y, contour)
        optimal_dist = (self.min_edge_distance + self.max_edge_distance) / 2
        distance_score = 1.0 - abs(edge_dist - optimal_dist) / (self.max_edge_distance - self.min_edge_distance)
        quality *= (0.5 + 0.5 * distance_score)

        # 缺陷附近惩罚
        for defect in defect_regions:
            dist_to_defect = self._distance_to_bbox(x, y, defect['bbox'])
            if dist_to_defect < 100:
                quality *= 0.5  # 严重惩罚

        # 轮廓曲率（曲率小的地方稳定性好）
        curvature = self._compute_curvature(x, y, contour)
        quality *= (1.0 - 0.2 * curvature)  # 曲率越大，扣分越多

        return quality

    def _distance_to_bbox(self, x, y, bbox):
        """点到边界框的距离"""
        x1, y1, x2, y2 = bbox
        dx = max(x1 - x, 0, x - x2)
        dy = max(y1 - y, 0, y - y2)
        return np.sqrt(dx**2 + dy**2)

    def _compute_curvature(self, x, y, contour):
        """计算局部曲率"""
        n = len(contour)
        idx = self._find_nearest_point(x, y, contour)
        if idx < 1 or idx >= n - 1:
            return 0

        # 三个临近点
        p1 = contour[(idx - 1) % n]
        p2 = contour[idx]
        p3 = contour[(idx + 1) % n]

        # 计算曲率（简单近似）
        v1 = np.array([p2[0] - p1[0], p2[1] - p1[1]])
        v2 = np.array([p3[0] - p2[0], p3[1] - p2[1]])

        cos_angle = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2) + 1e-6)
        curvature = (1 - cos_angle) / 2  # 归一化到[0,1]

        return curvature

    def _find_nearest_point(self, x, y, contour):
        """找到最近轮廓点索引"""
        min_dist = float('inf')
        min_idx = 0
        for i, (px, py) in enumerate(contour):
            dist = (x - px)**2 + (y - py)**2
            if dist < min_dist:
                min_dist = dist
                min_idx = i
        return min_idx
```

### 2.2 抓取点评价指标[51†]

| 指标 | 定义 | 优化目标 |
|-----|------|---------|
| **可达性** | 抓取点是否在机械臂工作空间内 | 最大化 |
| **稳定性** | 抓取后钢板是否会滑落 | 最大化 |
| **安全性** | 抓取过程是否会损伤钢板 | 最小化 |
| **效率** | 完成抓取所需时间和能量 | 最小化 |
| **避障** | 抓取路径是否有碰撞 | 无碰撞 |

**稳定性计算**：
$$S_{stability} = \mu \cdot F_n \cdot \frac{d}{2} - W \cdot \frac{d}{2}$$

其中：
- $\mu$：摩擦系数
- $F_n$：法向抓取力
- $d$ ：夹爪开口宽度
- $W$：钢板重量

## 3. 路径规划算法

### 3.1 基于采样的规划算法[52†][54†]

#### (1) RRT算法 (Rapidly-exploring Random Tree)

RRT通过随机采样快速探索空间，适合高维空间和复杂障碍物环境：

**算法流程**：
```
1. 初始化树，起始节点为根
2. 随机采样一个点 x_random
3. 在树中找到距离 x_random 最近的节点 x_nearest
4. 从 x_nearest 向 x_random 方向扩展步长 δ，得到新节点 x_new
5. 检查 x_new 是否碰撞
   - 无碰撞：将 x_new 加入树
   - 有碰撞：丢弃
6. 重复2-5，直至到达目标或达到最大迭代次数
```

**代码实现**：
```python
import numpy as np
import random

class RRTNode:
    """RRT节点"""
    def __init__(self, state, parent=None):
        self.state = state  # 状态向量
        self.parent = parent  # 父节点

class RRTPlanner:
    """RRT路径规划器"""

    def __init__(self, workspace_bounds, step_size=20, max_iterations=5000):
        """
        Args:
            workspace_bounds: 工作空间边界 [[x_min, x_max], [y_min, y_max], [z_min, z_max]]
            step_size: 扩展步长 (mm)
            max_iterations: 最大迭代次数
        """
        self.workspace_bounds = workspace_bounds
        self.step_size = step_size
        self.max_iterations = max_iterations
        self.nodes = []

    def plan(self, start, goal, obstacle_check_fn=None):
        """
        路径规划

        Args:
            start: 起点 [x, y, z]
            goal: 目标点 [x, y, z]
            obstacle_check_fn: 碰撞检测函数，接受状态，返回bool

        Returns:
            path: 路径点列表 或 None
        """
        # 创建起始节点
        start_node = RRTNode(np.array(start))
        self.nodes = [start_node]

        for _ in range(self.max_iterations):
            # 随机采样
            if random.random() < 0.1:  # 10%概率采样目标点
                random_state = np.array(goal)
            else:
                random_state = self._sample_random_state()

            # 找最近节点
            nearest_node = self._find_nearest(random_state)

            # 扩展
            new_node = self._steer(nearest_node, random_state)

            # 碰撞检测
            if obstacle_check_fn is None or not obstacle_check_fn(new_node.state):
                new_node.parent = nearest_node
                self.nodes.append(new_node)

                # 检查是否到达目标
                if np.linalg.norm(new_node.state - np.array(goal)) < self.step_size:
                    return self._extract_path(new_node)

        return None  # 规划失败

    def _sample_random_state(self):
        """采样随机状态"""
        state = []
        for low, high in self.workspace_bounds:
            state.append(random.uniform(low, high))
        return np.array(state)

    def _find_nearest(self, state):
        """找最近节点"""
        min_dist = float('inf')
        nearest = None
        for node in self.nodes:
            dist = np.linalg.norm(node.state - state)
            if dist < min_dist:
                min_dist = dist
                nearest = node
        return nearest

    def _steer(self, from_node, to_state):
        """从节点向目标方向扩展"""
        direction = to_state - from_node.state
        distance = np.linalg.norm(direction)

        if distance <= self.step_size:
            new_state = to_state
        else:
            new_state = from_node.state + (direction / distance) * self.step_size

        return RRTNode(new_state)

    def _extract_path(self, end_node):
        """提取路径"""
        path = []
        node = end_node
        while node is not None:
            path.append(node.state.tolist())
            node = node.parent
        path.reverse()
        return path
```

#### (2) RRT*算法 (优化的RRT)[54†]

RRT*在RRT基础上增加了**rewire**机制，逐渐优化路径代价：

**与RRT的区别**：
| 改进点 | RRT | RRT* |
|-------|-----|------|
| 父节点选择 | 仅最近节点 | 半径内代价最小节点 |
| 重连机制 | 无 | 有，更新邻居节点 |
| 最优性 | 非最优 | 渐近最优 |

**代码实现**：
```python
class RRTStarPlanner(RRTPlanner):
    """RRT*路径规划器"""

    def __init__(self, workspace_bounds, step_size=20, max_iterations=5000, rewire_radius=50):
        super().__init__(workspace_bounds, step_size, max_iterations)
        self.rewire_radius = rewire_radius
        self.cost = {0: 0}  # 节点索引到代价的映射

    def plan(self, start, goal, obstacle_check_fn=None):
        """RRT*规划"""
        start_node = RRTNode(np.array(start))
        self.nodes = [start_node]
        self.cost = {0: 0}

        for i in range(self.max_iterations):
            # 随机采样
            if random.random() < 0.1:
                random_state = np.array(goal)
            else:
                random_state = self._sample_random_state()

            # 找最近节点
            nearest_idx, nearest_node = self._find_nearest_with_idx(random_state)

            # 扩展
            new_node = self._steer(nearest_node, random_state)

            if obstacle_check_fn is not None and obstacle_check_fn(new_node.state):
                continue

            # RRT*改进：找最佳父节点
            new_node.parent, new_idx = self._find_best_parent(new_node, i)

            if new_node.parent is None:
                continue

            # 计算代价
            self.cost[new_idx] = self.cost[id(new_node.parent)] + \
                np.linalg.norm(new_node.state - new_node.parent.state)

            # 添加节点
            self.nodes.append(new_node)

            # Rewire
            self._rewire(new_node, new_idx, i)

            # 检查到达目标
            if np.linalg.norm(new_node.state - np.array(goal)) < self.step_size:
                return self._extract_path(new_node)

        return None

    def _find_best_parent(self, new_node, new_node_idx):
        """找代价最小的父节点"""
        best_parent = None
        best_cost = float('inf')
        best_idx = None

        for i, node in enumerate(self.nodes):
            dist = np.linalg.norm(new_node.state - node.state)
            if dist > self.step_size:
                continue

            if self._is_collision_free(node.state, new_node.state):
                cost = self.cost.get(i, float('inf')) + dist
                if cost < best_cost:
                    best_cost = cost
                    best_parent = node
                    best_idx = i

        return best_parent, best_idx

    def _rewire(self, new_node, new_idx, new_node_idx):
        """重连，更新邻居节点"""
        for i, node in enumerate(self.nodes):
            if i == new_idx:
                continue

            dist = np.linalg.norm(new_node.state - node.state)
            if dist > self.rewire_radius:
                continue

            if not self._is_collision_free(new_node.state, node.state):
                continue

            new_cost = self.cost[new_idx] + dist
            if new_cost < self.cost.get(i, float('inf')):
                # 更新父节点
                old_parent = node.parent
                node.parent = new_node
                self.cost[i] = new_cost

                # 更新所有子节点代价
                self._update_descendant_costs(node, old_parent)

    def _update_descendant_costs(self, node, old_parent):
        """更新后代节点代价"""
        # 简化：重新计算从根到该节点的路径代价
        pass

    def _find_nearest_with_idx(self, state):
        """找最近节点（带索引）"""
        min_dist = float('inf')
        nearest = None
        nearest_idx = None

        for i, node in enumerate(self.nodes):
            dist = np.linalg.norm(node.state - state)
            if dist < min_dist:
                min_dist = dist
                nearest = node
                nearest_idx = i

        return nearest_idx, nearest

    def _is_collision_free(self, state1, state2):
```

#### (3) RRT-Connect[52†]

双向RRT，从起点和目标同时生长：

```python
class RRTConnectPlanner:
    """RRT-Connect双向规划"""

    def __init__(self, workspace_bounds, step_size=20, max_iterations=5000):
        self.workspace_bounds = workspace_bounds
        self.step_size = step_size
        self.max_iterations = max_iterations

    def plan(self, start, goal, obstacle_check_fn=None):
        """RRT-Connect规划"""
        # 初始化两棵树
        tree_start = [RRTNode(np.array(start))]
        tree_goal = [RRTNode(np.array(goal))]

        for _ in range(self.max_iterations):
            # 从起始树扩展
            state = self._sample_random_state()
            nearest = self._find_nearest(tree_start, state)
            new_node = self._steer(nearest, state)

            if obstacle_check_fn is None or not obstacle_check_fn(new_node.state):
                new_node.parent = nearest
                tree_start.append(new_node)

                # 尝试连接目标树
                nearest_goal = self._find_nearest(tree_goal, new_node.state)
                if np.linalg.norm(new_node.state - nearest_goal.state) < self.step_size:
                    # 连接成功
                    return self._build_path(new_node, nearest_goal)

            # 从目标树扩展
            state = self._sample_random_state()
            nearest = self._find_nearest(tree_goal, state)
            new_node = self._steer(nearest, state)

            if obstacle_check_fn is None or not obstacle_check_fn(new_node.state):
                new_node.parent = nearest
                tree_goal.append(new_node)

                # 尝试连接起始树
                nearest_start = self._find_nearest(tree_start, new_node.state)
                if np.linalg.norm(new_node.state - nearest_start.state) < self.step_size:
                    # 连接成功
                    return self._build_path(nearest_start, new_node)

        return None

    def _build_path(self, node_start, node_goal):
        """构建路径"""
        path1 = self._extract_path(node_start)
        path2 = self._extract_path(node_goal)
        path2.reverse()
        return path1 + path2

    def _sample_random_state(self):
        """采样"""
        state = []
        for low, high in self.workspace_bounds:
            state.append(random.uniform(low, high))
        return np.array(state)

    def _find_nearest(self, tree, state):
        """找最近"""
        return min(tree, key=lambda n: np.linalg.norm(n.state - state))

    def _steer(self, from_node, to_state):
        """扩展"""
        direction = to_state - from_node.state
        distance = np.linalg.norm(direction)
        if distance <= self.step_size:
            new_state = to_state
        else:
            new_state = from_node.state + (direction / distance) * self.step_size
        return RRTNode(new_state)

    def _extract_path(self, end_node):
        """提取"""
        path = []
        node = end_node
        while node is not None:
            path.append(node.state.tolist())
            node = node.parent
        path.reverse()
        return path
```

### 4.1 路径平滑算法[52†]

RRT等采样算法生成的路径通常是折线，需要平滑处理：

#### (1) 梯度下降法

```python
def smooth_path_gradient(path, obstacles, iterations=100, step_size=0.1):
    """梯度下降法平滑路径"""
    smoothed = np.array(path, dtype=np.float64)

    for _ in range(iterations):
        for i in range(1, len(smoothed) - 1):
            # 计算路径平滑梯度
            smooth_grad = smoothed[i-1] + smoothed[i+1] - 2 * smoothed[i]

            # 计算障碍物梯度
            obs_grad = compute_obstacle_gradient(smoothed[i], obstacles)

            # 组合梯度更新
            smoothed[i] += step_size * (smooth_grad - 0.1 * obs_grad)

            # 碰撞检测
            if is_collision(smoothed[i], obstacles):
                smoothed[i] -= step_size * obs_grad

    return smoothed.tolist()

def compute_obstacle_gradient(point, obstacles, epsilon=1e-6):
    """计算障碍物梯度"""
    grad = np.zeros_like(point)
    for obs in obstacles:
        dist = np.linalg.norm(point - obs)
        if dist < 100:  # 安全距离
            grad += (point - obs) / (dist + epsilon)
    return grad
```

#### (2) B样条曲线平滑

```python
from scipy.interpolate import splprep, splev
import numpy as np

def b_spline_smooth(path, num_points=100):
    """
    B样条曲线平滑

    Args:
        path: 原始路径 [[x, y, z], ...]
        num_points: 采样点数

    Returns:
        smoothed: 平滑后的路径
    """
    if len(path) < 4:
        return path

    path = np.array(path)

    # 参数化
    t = np.linspace(0, 1, len(path))
    t_smooth = np.linspace(0, 1, num_points)

    # 对每个维度进行样条插值
    smoothed = np.zeros((num_points, path.shape[1]))
    for i in range(path.shape[1]):
        # 使用三次B样条
        k = 3 if len(path) > 3 else len(path) - 1
        tck, _ = splprep([path[:, i], t], s=0, k=k)
        smoothed[:, i] = splev(t_smooth, tck)[0]

    # 第三维用线性插值
    smoothed[:, 2] = np.interp(t_smooth, t, path[:, 2])

    return smoothed.tolist()
```

#### (3) 贝塞尔曲线平滑

```python
def bezier_smoothing(path, segments=10):
    """贝塞尔曲线平滑"""
    smoothed = []
    for i in range(len(path) - 1):
        p0 = np.array(path[i])
        p1 = np.array(path[i + 1])

        # 二次贝塞尔曲线，使用中点作为控制点
        mid = (p0 + p1) / 2

        for t in range(segments + 1):
            t_norm = t / segments
            # 二次贝塞尔公式: (1-t)²P0 + 2(1-t)tP1 + t²P2
            point = (1 - t_norm)**2 * p0 + 2 * (1 - t_norm) * t_norm * mid + t_norm**2 * p1
            smoothed.append(point.tolist())

    return smoothed
```

### 4.2 时间最优化[54†]

在路径平滑基础上，考虑时间最优性：

| 指标 | 优化目标 |
|-----|---------|
| **最短时间** | 最小化总执行时间 |
| **最小能量** | 最小化电机能耗 |
| **最大加速度** | 限制最大加速度 |
| **最小jerk** | 最小化加加速度（平滑轨迹） |

**轨迹生成方法**：
- 三次多项式：给定起止位置和速度
- 五次多项式：给定起止位置、速度、加速度
- S曲线：梯形速度规划，平滑加减速

```python
def quintic_polynomial_trajectory(q0, qf, v0, vf, a0, af, T):
    """
    五次多项式轨迹

    Args:
        q0, qf: 初始和终止位置
        v0, vf: 初始和终止速度
        a0, af: 初始和终止加速度
        T: 总时间

    Returns:
        trajectory: 轨迹函数 q(t)
    """
    # 五次多项式系数
    # q(t) = a0 + a1*t + a2*t^2 + a3*t^3 + a4*t^4 + a5*t^5

    a0_coef = q0
    a1_coef = v0
    a2_coef = a0 / 2

    # 求解 a3, a4, a5
    A = np.array([
        [T**3, T**4, T**5],
        [3*T**2, 4*T**3, 5*T**4],
        [6*T, 12*T**2, 20*T**3]
    ])
    b = np.array([qf - q0 - v0*T - a0*T**2/2, vf - v0 - a0*T, af - a0])

    a345 = np.linalg.solve(A, b)

    def trajectory(t):
        if t < 0:
            t = 0
        elif t > T:
            t = T

        return (a0_coef + a1_coef*t + a2_coef*t**2 +
                a345[0]*t**3 + a345[1]*t**4 + a345[2]*t**5)

    return trajectory
```

## 5. 多目标优化[54†]

### 5.1 多目标优化框架

实际抓取规划需要同时考虑多个目标：

| 目标 | 权重 | 说明 |
|-----|------|------|
| **路径长度** | w1 | 最短路径 |
| **安全性** | w2 | 最大离障碍物距离 |
| **平滑性** | w3 | 最小加速度/jerk |
| **可执行性** | w4 | 符合运动学约束 |
| **时间** | w5 | 最短执行时间 |

**多目标优化问题**：

$$\min_{path} J(path) = w_1 \cdot L(path) + w_2 \cdot S(path)^{-1} + w_3 \cdot J(path) + w_4 \cdot V(path) + w_5 \cdot T(path)$$

### 5.2 Pareto最优解[54†]

多目标优化通常没有单一最优解，而是Pareto最优解集：

```python
class MultiObjectiveOptimizer:
    """多目标优化器"""

    def __init__(self, weights=None):
        self.weights = weights or {
            'length': 0.3,
            'safety': 0.3,
            'smoothness': 0.2,
            'time': 0.2
        }

    def optimize(self, paths):
        """
        多目标优化

        Returns:
            pareto_front: Pareto前沿解列表
        """
        evaluated = []
        for path in paths:
            metrics = self._evaluate_path(path)
            score = self._compute_score(metrics)
            evaluated.append((path, metrics, score))

        # 非支配排序
        pareto_front = self._non_dominated_sort(evaluated)

        return pareto_front

    def _evaluate_path(self, path):
        """评估路径各项目标"""
        return {
            'length': self._compute_length(path),
            'safety': self._compute_safety(path),
            'smoothness': self._compute_smoothness(path),
            'time': self._compute_time(path)
        }

    def _compute_score(self, metrics):
        """计算加权得分"""
        return (self.weights['length'] * metrics['length'] +
                self.weights['safety'] * metrics['safety'] +
                self.weights['smoothness'] * metrics['smoothness'] +
                self.weights['time'] * metrics['time'])

    def _non_dominated_sort(self, evaluated):
        """非支配排序"""
        pareto = []
        for i, (path_i, metrics_i, _) in enumerate(evaluated):
            is_dominated = False
            for j, (path_j, metrics_j, _) in enumerate(evaluated):
                if i == j:
                    continue
                if self._dominates(metrics_j, metrics_i):
                    is_dominated = True
                    break
            if not is_dominated:
                pareto.append(path_i)

        return pareto

    def _dominates(self, a, b):
        """判断a是否支配b"""
        better_in_any = False
        for key in a:
            if a[key] > b[key]:
                better_in_any = True
            elif a[key] < b[key]:
                return False
        return better_in_any
```

```python
        action = self.actor(state).detach().numpy()
        if noise:
            action += np.random.randn(*action.shape) * 0.1
        action = np.clip(action, -self.action_bound, self.action_bound)

        # 采样
        states, actions, rewards, next_states, dones = replay_buffer.sample(batch_size)

        with torch.no_grad():
            next_actions = self.target_actor(next_states)
            target_q = self.target_critic(next_states, next_actions)
            target_q = rewards + gamma * (1 - dones) * target_q

        # 更新critic
        current_q = self.critic(states, actions)
        critic_loss = F.mse_loss(current_q, target_q)
        self.critic_optimizer.zero_grad()
        critic_loss.backward()
        self.critic_optimizer.step()

        # 更新actor
        actions_pred = self.actor(states)
        actor_loss = -self.critic(states, actions_pred).mean()
        self.actor_optimizer.zero_grad()
        actor_loss.backward()
        self.actor_optimizer.step()

        # 软更新目标网络
        self._soft_update(self.target_actor, self.actor, tau)
        self._soft_update(self.target_critic, self.critic, tau)

    def _soft_update(self, target, source, tau):
        """软更新"""
        for target_param, param in zip(target.parameters(), source.parameters()):
            target_param.data.copy_(tau * param.data + (1 - tau) * target_param.data)
```

| **位置控制** | 固定夹爪开度 | 刚性工件、已知尺寸 |
| **力位混合** | 位置控制+力反馈 | 通用场景 |
| **阻抗控制** | 末端呈现期望阻抗特性 | 接触任务 |
| **自适应力控** | 实时调整抓取力 | 尺寸变化、滑动检测 |

```python
def force_position_control(current_force, target_force, position, target_position,
                           kp_f=0.5, kp_p=0.1):
    """
    力位混合控制器

    Args:
        current_force: 当前力
        target_force: 目标力
        position: 当前位置
        target_position: 目标位置
        kp_f: 力控制比例增益
        kp_p: 位置控制比例增益

    Returns:
        output: 控制输出
    """
    # 力误差
    force_error = target_force - current_force
    force_adjustment = kp_f * force_error

    # 位置误差
    position_error = target_position - position
    position_adjustment = kp_p * position_error

    # 组合控制输出
    output = position_adjustment + force_adjustment
    return output

def impedance_control(desired_force, actual_force, actual_position,
                      M=1.0, B=10.0, K=100.0):
    """
    阻抗控制

    Args:
        desired_force: 期望力
        actual_force: 实际力
        actual_position: 实际位置
        M: 惯性参数
        B: 阻尼参数
        K: 刚度参数

    Returns:
        position_adjustment: 位置调整量
    """
    force_error = desired_force - actual_force
    # 阻抗关系: M*a + B*v + K*x = F
    # 简化为静态关系
    position_adjustment = force_error / K
    return position_adjustment
```

### 7.3 抓取稳定性检测[51†]

| 检测方法 | 原理 | 指标 |
|---------|------|------|
| **力矩检测** | 监测夹爪力矩突变 | 力矩 < 阈值 |
| **滑觉检测** | 传感器检测物体滑动 | 无滑动信号 |
| **位置偏差** | 末端位置偏差超限 | 偏差 < 阈值 |
| **视觉反馈** | 相机确认抓取状态 | 目标在视野内 |

```python
def grasp_stability_check(force_readings, torque_readings, expected_force):
    """
    抓取稳定性检测

    Returns:
        is_stable: 是否稳定
        stability_score: 稳定性评分 [0, 1]
    """
    # 力矩检查
    max_torque = max(abs(t) for t in torque_readings)
    if max_torque > TORQUE_THRESHOLD:
        return False, 0.0

    # 力值检查
    force_error = abs(sum(force_readings) - expected_force) / expected_force
    if force_error > FORCE_ERROR_THRESHOLD:
        return False, 0.0

    # 计算稳定性评分
    stability_score = 1.0 - min(1.0, force_error / FORCE_ERROR_THRESHOLD)
    return True, stability_score

def adaptive_force_control(current_force, target_force, slip_detected):
    """
    自适应力控

    Args:
        current_force: 当前力
        target_force: 目标力
        slip_detected: 是否检测到滑动

    Returns:
        new_target_force: 调整后的目标力
    """
    if slip_detected:
        # 检测到滑动，增加抓取力
        new_target_force = target_force * 1.2
        new_target_force = min(new_target_force, MAX_SAFE_FORCE)
    else:
        # 稳定，保持或略微减小
        new_target_force = target_force * 0.98

    return new_target_force
```

```python
from ompl import geometric as og
from ompl import base as ob

def plan_with_ompl(start, goal, bounds, obstacle_fn):
    """使用OMPL进行规划"""

    # 创建空间
    space = ob.RealVectorStateSpace(len(start))
    bounds_obj = ob.RealVectorBounds(len(start))
    for i, (low, high) in enumerate(bounds):
        bounds_obj.setLow(i, low)
        bounds_obj.setHigh(i, high)
    space.setBounds(bounds_obj)

    # 创建问题
    si = ob.SpaceInformation(space)
    si.setStateValidityChecker(ob.StateValidityCheckerFn(obstacle_fn))

    start_state = ob.State(space)
    goal_state = ob.State(space)
    for i, val in enumerate(start):
        start_state[i] = val
    for i, val in enumerate(goal):
        goal_state[i] = val

    pdef = ob.ProblemDefinition(si)
    pdef.setStartAndGoalStates(start_state, goal_state)

    # 设置规划器
    planner = og.RRTstar(si)
    planner.setProblemDefinition(pdef)

    # 解决
    planner.solve(5.0)  # 5秒

    if pdef.hasApproximateSolution():
        path = pdef.getSolutionPath()
        return path.getStates()
    return None
```

## 11. Anti-Interference-2D项目抓取系统实现

### 11.1 系统集成

```python
class SteelGraspSystem:
    """
    Anti-Interference-2D项目钢板抓取系统
    """

    def __init__(self, config):
        # 视觉模块
        self.edge_detector = SteelEdgeDetector()
        self.defect_detector = DefectDetector()

        # 规划模块
        self.grasp_selector = GraspPointSelector(config['grasp_point'])
        self.path_planner = RRTStarPlanner(
            config['path_planning']['workspace_bounds'],
            step_size=config['path_planning']['step_size'],
            max_iterations=config['path_planning']['max_iterations']
        )
        self.path_smoother = PathSmoother()

        # 控制模块
        self.robot_controller = RobotController()
        self.force_controller = ForceController()

    def execute_grasp(self, rgb_image, depth_image, polarization_info=None):
        """
        执行抓取任务

        Args:
            rgb_image: RGB图像
            depth_image: 深度图像
            polarization_info: 偏振信息

        Returns:
            success: 是否成功
            result: 结果信息
        """
        # 1. 视觉感知
        edges, contours, _ = self.edge_detector.detect(rgb_image, polarization_info)
        defects = self.defect_detector.detect(rgb_image)

        # 2. 选择抓取点
        grasp_points = self.grasp_selector.select_grasp_points(
            contours[0], defects, edges)

        if not grasp_points:
            return False, "无可用抓取点"

        best_grasp = grasp_points[0]

        # 3. 路径规划
        current_pos = self.robot_controller.get_current_position()
        goal_pos = best_grasp['point'] + [best_grasp.get('height', 100)]

        path = self.path_planner.plan(
            current_pos, goal_pos,
            obstacle_check_fn=self._check_collision
        )

        if path is None:
            return False, "路径规划失败"

        # 4. 路径平滑
        smoothed_path = self.path_smoother.b_spline_smooth(path)

        # 5. 执行抓取
        self.robot_controller.execute_path(smoothed_path)

        # 6. 力控抓取
        target_force = self.config['motion']['target_force']
        self.force_controller.grasp(target_force)

        # 7. 稳定性检测
        is_stable, score = self.force_controller.check_stability()
        if not is_stable:
            self.robot_controller.release()
            return False, f"抓取不稳定 (score={score})"

        return True, {
            'grasp_point': best_grasp,
            'stability_score': score,
            'path_length': len(smoothed_path)
        }
```
