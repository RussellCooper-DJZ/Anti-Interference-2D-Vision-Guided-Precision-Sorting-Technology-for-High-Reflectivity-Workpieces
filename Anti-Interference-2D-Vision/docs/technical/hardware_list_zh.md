# 硬件清单

本高反光工件抗干扰2D视觉引导精准分拣技术方案所需的硬件组件如下：

## 1. 核心处理单元

*   **瑞萨 RA8P1 微控制器开发板**：搭载 Arm Cortex-M85 核心，用于运行嵌入式视觉算法和控制逻辑。建议选用官方评估板或定制开发板。

## 2. 图像采集系统

*   **工业相机**：
    *   **类型**：高分辨率（例如 500 万像素或更高）、高帧率（例如 60fps 或更高）的全局快门 CMOS 工业相机。
    *   **接口**：兼容 RA8P1 的 CSI-2 接口或其他高速接口（如 USB3.0，需通过桥接芯片）。
    *   **功能**：具备 HDR 功能或支持多重曝光模式。
*   **工业镜头**：
    *   **类型**：低畸变、高解析度的定焦镜头。
    *   **焦距**：根据工作距离和视野范围选择合适的焦距。
*   **偏振滤镜 (可选)**：如果采用硬件偏振成像，需在镜头前安装偏振滤镜。

## 3. 照明系统

*   **漫射光源**：
    *   **类型**：积分球光源、穹顶光源或环形漫射光源。
    *   **功率**：根据工件反光特性和环境光照条件选择合适功率，确保均匀照明。
*   **偏振光源 (可选)**：如果采用硬件偏振成像，需使用偏振光源。
*   **光源控制器**：用于精确控制光源的亮度、闪光模式等。

## 4. 机器人系统

*   **工业机器人**：六轴或多轴工业机器人，具备高精度重复定位能力。
*   **机器人控制器**：与 RA8P1 进行通信，接收视觉引导指令并执行抓取动作。
*   **末端执行器**：根据工件形状和材质选择合适的夹爪或吸盘。

## 5. 标定工具

*   **高精度标定板**：用于相机内参标定和手眼标定，例如棋盘格、ChArUco 板或点阵标定板。

## 6. 辅助设备

*   **电源**：为所有硬件组件提供稳定电源。
*   **工业电脑 (PC)**：用于算法开发、模型训练、手眼标定以及与 RA8P1 的通信调试。
*   **显示器**：用于调试和监控。
*   **连接线缆**：包括相机数据线、电源线、通信线等。

## 7. 软件环境

*   **开发工具链**：瑞萨 e2 studio IDE、Arm GNU Toolchain。
*   **FSP (Flexible Software Package)**：瑞萨提供的软件开发包，包含驱动和中间件。
*   **TensorFlow Lite for Microcontrollers (TFLM)**：用于在 RA8P1 上部署深度学习模型。
*   **OpenCV (PC 版)**：用于 PC 端的图像处理算法开发和验证。
*   **Python/PyTorch/TensorFlow (PC 版)**：用于深度学习模型的训练和转换。
*   **机器人编程环境**：机器人厂商提供的编程软件。

## 8. 增强型组件（2026-04-23 更新）

### 8.1 PBR 光照系统组件

用于增强型 PBR（基于物理的渲染）光照模拟：

| 组件 | 规格 | 用途 |
|------|------|------|
| **多向 LED 阵列** | ≥4 方向，0-100% 强度控制 | 模拟复杂工业光照 |
| **高强度定向 LED** | ≥10000 Lux 等效 | `pbr_sun` 模式日光模拟 |
| **反射表面装置** | 哑光黑 + 镜面表面 | `pbr_mixed` 水面反射模式 |

### 8.2 推理计算组件

| 组件 | 规格 | 使用场景 |
|------|------|----------|
| **NVIDIA GPU（训练）** | CUDA 兼容 GPU，≥8GB VRAM | PBR 数据生成、模型训练 |
| **ONNX Runtime（边缘）** | RA8P1 的 Helium 优化版本 | 嵌入式推理，~40ms 延迟 |
| **TensorRT（可选）** | 需要 NVIDIA GPU | PC/边缘推理，~10ms 延迟 |

### 8.3 ABB 机器人接口组件

用于 AbbRobotEGM UDP EGM 协议接口：

| 组件 | 规格 | 用途 |
|------|------|------|
| **ABB 机器人控制器** | IRC5 或更新版本，带 EGM 选项 | 真实机器人控制 |
| **网络交换机** | 1000Mbps，低延迟 | UDP EGM 通信（端口 6510） |
| **EGM 配置** | Protobuf 或二进制回退格式 | RobotStudio 集成 |
